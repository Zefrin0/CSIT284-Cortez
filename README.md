# Ledger & Lime

An interactive Flutter expense tracker built for Lesson 5: Interactivity & Theming.

## Features

- Add expenses through a validated modal form.
- Choose a date and category with Material input controls.
- View a running monthly total and expense count.
- Swipe an item away and undo the deletion from the snackbar.
- Responsive list layout for narrow and wide screens.
- Custom light and dark Material 3 themes with a teal and lime-inspired palette.

## Run locally

```shell
flutter pub get
flutter run
```

Run the tests with:

```shell
flutter test
```

The app uses only Flutter SDK packages and does not require an external service.
